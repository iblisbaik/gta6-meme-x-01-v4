## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` reads the X post URL from `POST.json`, validates it is an
`x.com/<handle>/status/<id>` address, and writes it to
`$MAKEFUN_OUTPUT_DIR/POST.json`.
